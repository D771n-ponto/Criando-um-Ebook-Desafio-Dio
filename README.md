# 📚 Desafio de Projeto: Criando um Ebook com IA Generativa

Este repositório contém a documentação, os prompts e os arquivos finais do desafio prático focado em Engenharia de Prompt e criação de um eBook profissional utilizando ferramentas de Inteligência Artificial.

---

## 📖 Sobre o eBook
* **Título:** Dominando o AWS Lambda: O Guia Prático para Arquiteturas Serverless
* **Foco:** Abordar conceitos fundamentais de computação orientada a eventos, escalabilidade e redução de custos operacionais na nuvem.

## 🛠️ Tecnologias e Ferramentas Utilizadas

| Etapa do Processo | Ferramenta Utilizada | Função |
| :--- | :--- | :--- |
| **Geração de Conteúdo** | Gemini (Google) | Atuou como especialista técnico para estruturar os capítulos, criar títulos impactantes e redigir o corpo de texto. |
| **Identidade Visual (Capa)** | Craiyon | Criação da arte da capa text-to-image com estética geométrica moderna e cores da AWS. |
| **Diagramação e Layout** | Canva / Google Docs | Organização visual das páginas e exportação do arquivo final no formato padronizado PDF. |

---

## 🧠 Engenharia de Prompts Aplicada

### 📝 Prompt para Criação de Conteúdo (Gemini):
> *"Atue como um redator técnico especialista em DevOps e Cloud Computing. Escreva o conteúdo de um eBook curto de 3 páginas sobre os conceitos fundamentais do AWS Lambda e arquitetura Serverless, focado em iniciantes e utilizando um tom profissional e didático."*

### 🎨 Prompt para Criação da Capa (Craiyon):
> *"A professional book cover design for a technology book titled 'AWS Lambda'. Minimalist and modern background with neon orange and white colors, geometric patterns representing cloud networks, 3d render style."*
